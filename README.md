# Credit Risk Assessment & Decision Support System

An end-to-end **Explainable Machine Learning** application for synthetic credit-risk analytics, simulated loan-default prediction, model evaluation, feature-importance analysis, and interactive financial decision support.

> **Responsible Use Notice:** This project uses synthetic applicant and loan data with simulated default labels. Probabilities, metrics, and risk estimates are intended for analytical and software-demonstration purposes only and are not validated for real-world lending, underwriting, or financial decisions.

## Overview

The **Credit Risk Assessment & Decision Support System** implements a complete analytics workflow from data preparation through model training, evaluation, explainability, reporting, and interactive application delivery.

### Core Capabilities

- Synthetic credit-risk dataset generation and validation
- Data-quality inspection and exploratory data analysis
- Feature preparation and train/test separation
- Multi-model classification and performance comparison
- Applicant-level simulated default-probability estimation
- Confusion-matrix, ROC, and Precision-Recall analysis
- Permutation feature importance
- SHAP-based model explainability
- Reusable serialized model artifacts using
